# 定時

飛んでくる「ちょっといい？」をスワイプでかわして、定時退社を死守するエンドレスミニゲームです。

## スマホで開く

1. このフォルダを静的サイトとして配信する（下の「手元で起動」）。
2. スマホとパソコンを同じWi-Fiにつなぐ。
3. パソコンに出たアドレスを、スマホのブラウザで開く。
4. 画面はたて持ち。親指で左右にスワイプ、または画面の左右をタップしてかわす。
5. Safariなら共有メニューから「ホーム画面に追加」すると、アプリのように開けます。一度開けば、通信がなくても遊べます。

ファイルを直接開く場合は、`index.html` をブラウザにドラッグしても遊べます。

## 手元で起動

ビルドは不要です。リポジトリの直下にある `index.html` が本体です。

```bash
python3 -m http.server 43123
```

ブラウザで <http://127.0.0.1:43123> を開きます。

パソコンでは、左右キー（または A / D）でも動かせます。スペースキーでスタートとリトライができます。

## 遊び方

- 「帰る」で退社開始。
- 上から落ちてくる吹き出しをかわすと、守った分数が増えます。
- ぶつかると「残業確定」。記録はこの端末に残ります。
- 時間がたつと速くなり、大きい「部長」も飛んできます。

## 公開URL

この環境には公開用のホスティング認証がないため、デモサイトは置いていません。配信するときはリポジトリ直下をそのまま静的ホスティングしてください。入口は `index.html` です。
